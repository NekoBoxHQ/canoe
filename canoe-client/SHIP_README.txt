  轻舟 / Canoe
  轻舟已过万重山  ·  One boat, one tap.
════════════════════════════════════════════════════════════════


怎么用
──────────────────────────────────────────────────────────────

  1. 解压后双击 Canoe.exe

  2. 第一次用点「去造舟」注册一个账号
       用户名 3-32 位字母数字下划线
       密码至少 8 位
     账号在服务器上，**必须联网**。注册完会自动登舟。

  3. 点「启航」→ 状态变「已启航」，代理生效
     点「靠岸」→ 状态变「已靠岸」，代理停止

  默认是「系统代理」模式，浏览器等程序立刻生效。


关窗不等于退出
──────────────────────────────────────────────────────────────

  点右上角的 ✕ 只是把界面**收进任务栏托盘**，代理照常跑。

  要真正退出：**右键托盘里的轻舟图标 → 退出**
  （退出时会先还原系统代理，再关掉内核，不会让你断网）


注意：解压后要整个文件夹一起
──────────────────────────────────────────────────────────────

  不要只把 Canoe.exe 拖出来 —— 它需要旁边的 _internal 目录
  （内核、规则集、图标都在里面）才能跑。


可选设置（两排，各选各的）
──────────────────────────────────────────────────────────────

        ○ 分流            ○ 全局
        ☑ 系统代理        ☐ TUN 模式

  第一排 · 分流模式（二选一）
    ◉ 分流   默认。局域网和大陆网站走直连，其余走代理
    ○ 全局   所有流量都走代理

  第二排 · 接管方式（可以同时勾）
    ☑ 系统代理   默认开。把 Windows 代理指向本机端口，不需要管理员权限
    ☐ TUN 模式   默认关。接管全部流量，需要管理员权限 + wintun.dll


三个工具按钮
──────────────────────────────────────────────────────────────

  更新      检查客户端有没有新版本，同时刷新订阅
  TCping    测本机到节点的握手延迟（4 次，报最小/平均/最大/丢包）
  URL测试   测整条链路能不能上网（需要先启航）


结果框
──────────────────────────────────────────────────────────────

  主界面下面那一行绿字，只显示**最新一条**结果：

      TCP 延迟：38ms

  它刻意不是日志框 —— 完整内核日志里有节点地址，显示出来会暴露
  节点信息。出问题就先看这一行。


关于节点
──────────────────────────────────────────────────────────────

  节点不在客户端里，是登舟后从服务器**加密下发**的，只在内存里解密使用。

  这意味着：
    · 订阅被停用、账号到期或被封禁，客户端下次交互就会发现，
      就地清掉本地订阅，正在航行的会自动靠岸；
    · 客户端关闭后重新打开，会重新向服务器要一次。

  如果启航时提示「服务端没有下发订阅」，说明账号那边还没配节点 ——
  找管理员在后台加上，不是客户端的问题。


常见问题
──────────────────────────────────────────────────────────────

  首次运行提示「已保护你的电脑」
      未做代码签名。点「更多信息」→「仍要运行」。

  提示「连不上渡口」
      检查网络；或者服务器地址/端口不对（地址写死在客户端里，
      换服务器需要重新发一版客户端）。

  启航失败、提示缺 sing-box
      多半是杀毒软件把 _internal\bin\sing-box.exe 删了。
      整个文件夹加白名单后重新解压。

  TUN 模式勾了但启航失败
      TUN 需要管理员权限。勾选后它会问你要不要以管理员身份重启，
      点是即可。另外 _internal\bin\ 下必须有 wintun.dll。


自检
──────────────────────────────────────────────────────────────

  出问题先跑这个，结果会写到 %APPDATA%\Canoe\selftest.txt：

      Canoe.exe --selftest

  退出码 0 = 正常，2 = 缺内核或缺资源
