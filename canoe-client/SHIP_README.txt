怎么用（最快路径 · 3 秒）
──────────────────────────────────────────────────────────────

1. 双击 Canoe.exe

2. 点中间那个「直接体验（跳过注册）」
   → 不用注册，直接进主界面

3. 点「启航」→ 状态变「已启航」，代理生效
   点「靠岸」→ 状态变「已靠岸」，代理停止

   默认是「系统代理」模式，浏览器等程序立刻生效。

   （打包时文件夹里已有「使用说明.txt」，内容相同）


如果你想试注册流程
──────────────────────────────────────────────────────────────

界面右下角有「去造舟」：
  用户名 3-32 位字母数字，密码至少 8 位（要输两遍）
  这是本地假账号，随便填

注册完会自动登舟。「直接体验」走的也是本地账号，
账号名是「访客」，随时可以在主界面右下角「离舟」退出。


注意
──────────────────────────────────────────────────────────────

解压后要**整个文件夹一起**，不要只把 Canoe.exe 拖出来，
它需要旁边的 _internal 目录才能跑。


可选设置（两排，各选各的）
──────────────────────────────────────────────────────────────

        ○ 分流            ○ 全局
        ☑ 系统代理        ☐ TUN 模式

  第一排 · 分流模式（二选一）
    ◉ 分流   默认。局域网和大陆网站走直连，其余走代理
    ○ 全局   所有流量都走代理

  第二排 · 接管方式（可以同时勾）
    ☑ 系统代理   默认开。把 Windows 代理指向本机端口，不需要管理员权限
    ☐ TUN 模式   默认关。接管全部流量，需要管理员权限 + wintun.dll

  两排互不影响，第二排的两个也可以同时勾上。
  TUN 模式下 IPv4 和 IPv6 一起接管，不用另外设置。


关于「全局 (TUN)」模式
──────────────────────────────────────────────────────────────

这个模式需要管理员权限：

  不是管理员时程序会问你要不要提权重启，点「是」即可

  （wintun.dll 已经打进包里了，不用另外下载）

只测系统代理模式的话，连管理员权限都不需要。


出问题了怎么办
──────────────────────────────────────────────────────────────

1. 先跑自检

     双击运行前，按住 Shift 右键 Canoe.exe → 在此处打开命令窗口，
     执行：

         Canoe.exe --selftest

     或者在文件管理器地址栏输入 cmd 打开命令行后执行同样命令。
     它会把内核路径、版本、规则集是否就位打印出来，
     并写到 %APPDATA%\Canoe\selftest.txt

2. 看状态栏提示
     错误信息会显示在「启航」「靠岸」下方那一行，
     文案是「风浪太大，请重试」+ 具体原因。

3. 常见情况
     · 点了启航没反应 / 提示风浪太大
       → 多半是网络连不上测试节点，或节点已失效

     · 浏览器还是上不了网
       → 系统代理模式只影响读取系统代理设置的程序。
         有些程序（部分游戏、终端工具）不读系统代理，
         需要切到全局(TUN)模式

     · 关掉程序后上不了网
       → 正常情况程序会自动还原系统代理。
         如果异常退出导致没还原，手动改回来：
         设置 → 网络和 Internet → 代理 → 关掉「使用代理服务器」


已知限制（这是阶段1，不是完整体）
──────────────────────────────────────────────────────────────

  · 节点是写死的测试节点，账号是本地假账号
    → 正式的账号系统和节点下发在阶段3

  · 「启航」之前界面上就会显示节点名，但那是写死的名字，
    不代表已连接。以状态文字为准。

  · 没有流量统计、没有限速

  · 未做代码签名，首次运行 Windows 可能提示
    「已保护你的电脑」→ 点「更多信息」→「仍要运行」
