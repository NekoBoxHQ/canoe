怎么用（最快路径 · 3 秒）
──────────────────────────────────────────────────────────────

1. 双击 Canoe.exe

2. 点中间那个「直接体验（跳过注册）」
   → 不用注册，直接进主界面

3. 点「启航」→ 状态变「已启航」，代理生效
   点「靠岸」→ 状态变「已靠岸」，代理停止

   默认是「系统代理」模式，浏览器等程序立刻生效。

   （打包时文件夹里已有「使用说明.txt」，内容相同）


如果你想试注册流程
──────────────────────────────────────────────────────────────

界面右下角有「去造舟」：
  用户名 3-32 位字母数字，密码至少 8 位（要输两遍）
  这是本地假账号，随便填

注册完会自动登舟。「直接体验」走的也是本地账号，
账号名是「访客」，随时可以在主界面右下角「离舟」退出。


注意
──────────────────────────────────────────────────────────────

解压后要**整个文件夹一起**，不要只把 Canoe.exe 拖出来，
它需要旁边的 _internal 目录才能跑。


可选设置（两排，各选各的）
──────────────────────────────────────────────────────────────

        ○ 分流            ○ 全局
        ☑ 系统代理        ☐ TUN 模式

  第一排 · 分流模式（二选一）
    ◉ 分流   默认。局域网和大陆网站走直连，其余走代理
    ○ 全局   所有流量都走代理

  第二排 · 接管方式（可以同时勾）
    ☑ 系统代理   默认开。把 Windows 代理指向本机端口，不需要管理员权限
    ☐ TUN 模式   默认关。接管全部流量，需要管理员权限 + wintun.dll

  两排互不影响，第二排的两个也可以同时勾上。


三个工具按钮
──────────────────────────────────────────────────────────────

  🔄 更新      检查客户端有没有新版本（阶段4 配好地址后才有效）
  📡 TCping    测本机到节点的延迟（4 次，报最小/平均/最大/丢包）
  🔗 URL测试   测整条链路能不能上网（需要先启航）


测试结果框
──────────────────────────────────────────────────────────────

  主界面下面那个小绿字框，只显示三种结果：

      更新：1.0.0 最新
      TCP 延迟：38ms
      URL 耗时：344ms

  它**不是日志框** —— 完整内核日志里带节点域名，显示出来会暴露
  节点信息，所以刻意不显示。出问题就先看这三行。


已知限制（这是阶段1，不是完整体）
──────────────────────────────────────────────────────────────

  · 节点是写死的测试节点，账号是本地假账号
    → 正式的账号系统和节点下发在阶段3

  · 「启航」之前界面上就会显示节点名，但那是写死的名字，
    不代表已连接。以状态文字为准。

  · 没有流量统计、没有限速

  · 未做代码签名，首次运行 Windows 可能提示
    「已保护你的电脑」→ 点「更多信息」→「仍要运行」
